# 下载页多选工具栏

入口：设置 → 样式 → 下载页多选工具栏。

- 下载、归档两个标签分别保存按钮开关和顺序；普通列表、网格共用对应配置。
- 开关决定是否显示，拖动右侧手柄调整顺序；关闭的按钮保留原位置。
- 当前标签右上角的重置按钮只恢复本标签。
- 底部固定实时预览模拟已选中项目，按钮不执行任何任务，可横向滚动查看。
- 实际底栏的退出多选按钮固定在右侧，不允许隐藏；其余按钮在窄屏横向滚动。
- 没有选中项目时，只有全选与退出多选可操作。实际业务回调与确认框保持不变。
- 下载/归档的列表与网格在全选后同时刷新底栏，避免动作仍停留在禁用状态。
- 归档中的机器人图标是“切换归档解析来源”，不是 AI 功能。
- 批量更新（环形更新图标）在下载与归档中均可配置，见 [批量更新说明](download-batch-update.md)。
- 本地页没有多选功能，因此不提供第三份配置。

配置存入现有 StyleSetting JSON 的 `galleryMultiSelectToolbar` 和
`archiveMultiSelectToolbar`，各自包含稳定字符串 ID 的 `order` 与 `enabled`。
不改数据库版本，不保存图标编码、翻译文字或 enum 下标。未知 ID 被忽略，重复 ID
去重，缺少的 ID 追加并采用默认开启；旧配置缺字段、格式非法均有默认值。
已存在 order 中的按钮即使全部关闭也能保持关闭状态。

保存期间暂时禁用编辑控件。工具栏编辑与其他整份样式配置写入共用串行队列，
每次编辑在执行时从最新确认状态计算，失败恢复该次之前状态，再放行下一次写入。
因此不会发生旧失败回滚覆盖新设置、或其他样式保存将失败工具栏写回的问题。
错误在全局通知提示并写日志；退出页面不取消保存。

预览使用与实际底栏相同组件，只有无副作用的空回调，确保图标显示与真实底栏一致；
拖动/滚动不会触发收藏、删除、下载等业务操作。

定向测试：

```sh
fvm flutter test --no-pub test/download_multi_select_toolbar_config_test.dart test/download_multi_select_toolbar_widget_test.dart
```

手动验收：分别隐藏、重排两页按钮，检查预览与实际底栏一致；关闭全部按钮；
重启后检查配置保留；窄屏滚动时退出按钮保持可见；下载/归档列表与网格共用配置。
